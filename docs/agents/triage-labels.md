# Triage Labels

These labels exist in the Personal team in Linear and apply to Creuza issues.

| Canonical role | Linear label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an AFK agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill mentions a triage role, use its mapped Linear label. Preserve unrelated labels when updating an issue. Triage labels describe readiness or disposition; Linear workflow statuses describe implementation progress.

Edit the Linear label column if the team's vocabulary changes.
